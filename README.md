# SPLASH Salons — Premium Static Demo

Built with pure HTML, CSS and JavaScript.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Included
- Premium editorial salon UI
- Responsive desktop/tablet/mobile layouts
- Sticky glass navigation + animated mobile menu
- Hero zoom/reveal animations
- Services, locations, gallery, testimonials, booking and contact sections
- Real Treatwell booking links supplied in the brief
- Phone + WhatsApp CTAs
- Client-side contact form validation/success state
- Reduced-motion support
- Remote high-resolution Unsplash photography for the demo

## Important
The contact form is intentionally demo-only and does not send email.
Images are loaded from Unsplash URLs; replace them with licensed SPLASH photography for production.
